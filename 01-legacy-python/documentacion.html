¿Qué hace FRAN?

Un pipeline automatizado que convierte hojas de respuestas en un informe de liderazgo completo, sin intervención manual.

📋

Ingesta de respuestas

Lee 133 respuestas de 5 tests psicométricos (NEO, CELID, POTENLID, CAMIN, CONLID) definidas en diccionarios Python.

⚙️

Corrección y normas

Aplica claves de corrección estándar, puntuación inversa, y baremos de normas poblacionales importados desde Excel para calcular T-scores y percentiles.

📊

Visualización

Genera automáticamente 3 gráficos matplotlib: perfil NEO, estilos de liderazgo y mapa de competencias radial evaluado vs. ideal.

📄

Informe Word profesional

Construye un documento .docx de 5 secciones heredando el template institucional: tablas con código de colores, gráficos incrustados y marco teórico.

🔁

Reproducible

Para evaluar a un nuevo líder basta cambiar los diccionarios de respuestas en corregir.py y ejecutar los 3 scripts. Sin tocar nada más.

📁

Trazabilidad total

Guarda respuestas crudas en Markdown y un log de sesión con metodología, resultados y protocolo de reproducción.

Paso 1 — Respuestas del evaluado

Los 133 ítems de los 5 instrumentos se cargan como diccionarios Python en corregir.py o se registran en respuestas_evaluado.md para trazabilidad.

# NEO-FFI: 60 respuestas (letras a–e) neo_resp = {1:'d', 2:'c', 3:'a', ..., 60:'b'} # CELID-A: 34 ítems (escala 1–5) celid = {1:4, 2:5, 3:3, ..., 34:2} # POTENLID: 9 ítems, CAMIN: 12 ítems, CONLID: 18 ítems poten = {1:5, ...} | cam = {1:6, ...} | con = {1:4, ...}

Paso 2 — corregir.py: Motor de corrección

Aplica las claves estándar Costa & McCrae, puntaje inverso en 28 ítems, y mapea puntajes brutos a T-scores usando tablas de baremos importadas de Excel (Casullo & Pérez 2008).

# Clave NEO: {ítem: (dimensión, dirección)} neo_key = { 1: ('N', 1), # Neurotismo, directo 6: ('N', -1), # Neurotismo, inverso ... } # Conversión letra → valor (0–4) letra_val = {'a':0, 'b':1, 'c':2, 'd':3, 'e':4} # Mapeo bruto → T-score via tabla Excel def tscore(bruto, tabla_dim): return tabla_dim[bruto] # lookup directo # Percentil para CELID / CAMIN / CONLID / POTENLID def percentil(valor, baremo): for p, corte in sorted(baremo.items(), reverse=True): if valor >= corte: return p

Paso 4 — generar_informe.py: Informe Word

Abre el template institucional MODELO_DE_INFORME_1.docx, limpia el cuerpo preservando estilos y construye 5 secciones dinámicamente con python-docx.

from docx import Document from docx.shared import RGBColor, Pt, Inches doc = Document('MODELO_DE_INFORME_1.docx') # Limpiar cuerpo, preservar sección/estilos institucionales for elem in list(doc.element.body): doc.element.body.remove(elem) # Tablas con color condicional por nivel colores = {'Alto':'#3fb950', 'Medio':'#d29922', 'Bajo':'#e63946'} # Insertar gráficos doc.add_picture('grafico_neo.png', width=Inches(6)) doc.add_picture('grafico_radar.png', width=Inches(6)) doc.save('INFORME_LIDERAZGO.docx')

Instrumentos psicométricos

Los 5 tests que evalúa FRAN

Hacé clic en cada instrumento para ver detalles, dimensiones y proceso de corrección.

NEO-FFI

Inventario de Personalidad (Big Five)

60 ítems Escala a–e (0–4) 5 T-scores
▼

Evalúa los 5 grandes factores de personalidad de Costa & McCrae (1992). Es el instrumento más complejo: usa puntuación inversa en 28 de sus 60 ítems y normas españolas (Casullo & Pérez 2008).

N — Neurotismo
E — Extraversión
O — Apertura a la experiencia
A — Amabilidad
C — Responsabilidad
Proceso de corrección:
  1. Convierte letra (a–e) a valor numérico (0–4)
  2. Aplica inversión: valor_correcto = 4 - valor_raw (para los 28 ítems marcados)
  3. Suma los 12 ítems de cada dimensión → puntaje bruto (0–48)
  4. Mapea bruto → T-score via tabla baremo Excel (media=50, DS=10)
  5. Clasifica nivel: T<35=Muy Bajo, 35–44=Bajo, 45–54=Medio, 55–64=Alto, >64=Muy Alto

Recompensa contingente
Dirección por excepción
Laissez-Faire

● Transformacional ● Transaccional ● Laissez-Faire

Estructura del informe INFORME_LIDERAZGO.docx

5 secciones generadas automáticamente desde el template institucional.

1
Datos cuantitativos

Tablas con todos los scores, percentiles y niveles de los 5 instrumentos. Celdas con código de color: verde=Alto, amarillo=Medio, rojo=Bajo.

2
Resultados cualitativos

Narrativa detallada por dimensión: qué implica cada score en el contexto del liderazgo. Integra los 5 tests con coherencia teórica.

3
Perfil integrado

Síntesis que conecta personalidad (NEO) con conductas de liderazgo (CELID, CAMIN, CONLID) y motivación (POTENLID).

4
Mapa de competencias (gráfico)

Gráfico radar incrustado: evaluado (rojo) vs. líder situacional ideal (azul). Identifica brechas visualmente.

5
Marco teórico y recomendaciones

5 competencias de liderazgo con descripción teórica y plan de desarrollo personalizado basado en el perfil.

Uso

Cómo evaluar a un nuevo líder

3 pasos para reproducir el proceso con cualquier evaluado.

1️⃣

Cargar respuestas

Editar los diccionarios en corregir.py con las respuestas del nuevo evaluado. NEO (60 letras a–e), más 73 valores numéricos de los otros 4 tests.

2️⃣

Ejecutar el pipeline

python3 corregir.py
python3 graficos.py
python3 generar_informe.py
3️⃣

Recibir entregables

En la misma carpeta aparecen INFORME_LIDERAZGO.docx y los 3 gráficos PNG, listos para compartir o imprimir.
